# photoneu
## Light treatment for mice by computer vision and CNC Photobiomodulation
This project implement Convexity Defects Algorithm for segmenting overlapping mice from topview images.
The main algorithm uses 2 datasets:
- Trimouse-161: https://zenodo.org/records/5851157
- movAI: https://doi.org/10.5281/zenodo.24347098
